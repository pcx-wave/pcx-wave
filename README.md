## AI engineering

- **Harnessing**: Claude orchestrates, cheaper models do the work, and every result is checked and reviewed as a diff.
- **Context engineering**: keep the orchestrator's context small, with summaries instead of source, pre-digested codebase slices and a memory of past sessions over MCP.
- **Prompt design**: prompts written as contracts with checkable output.
